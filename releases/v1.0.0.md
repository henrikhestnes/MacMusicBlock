# MacMusicBlock 1.0.0

Stops Apple Music from opening, from the menu bar.

- Quits Apple Music as soon as it launches, whether from the play key, connecting headphones, or opening an audio file.
- Optionally opens another app, such as Spotify, in its place.
- Pause blocking from the menu bar when you want to use Apple Music.

Requires macOS 13 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macmusicblock
```

Or download `MacMusicBlock.zip`, unzip it, and move **MacMusicBlock.app** to **Applications**.

This build is ad-hoc signed and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.

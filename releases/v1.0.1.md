# MacMusicBlock 1.0.1

Releases are now signed with a stable self-signed certificate instead of an ad-hoc signature.

- Every release from this one on has the same signer, so an installed copy can be checked against it with `codesign -dr - /Applications/MacMusicBlock.app`.
- macOS may ask you to approve **Launch at Login** again after this update.
- No functional changes.

Requires macOS 13 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/macmusicblock
```

Or download `MacMusicBlock.zip`, unzip it, and move **MacMusicBlock.app** to **Applications**.

Existing Homebrew users can run `brew update` followed by `brew upgrade --cask macmusicblock`.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
